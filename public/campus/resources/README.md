# Runtime resources

[`fonts/fusion-pixel/`](fonts/fusion-pixel/) contains the locally bundled Traditional/Simplified Chinese pixel fonts and their license/source records. Runtime images are in [`../images/`](../images/), and fixed voice files are in [`../audio/`](../audio/).

Non-runtime artwork, design decisions and production evidence live in the repository's [`resources/`](../../../resources/) folder; documentation lives in [`docs/`](../../../docs/).
