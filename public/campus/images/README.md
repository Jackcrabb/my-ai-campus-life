# Runtime images

| Folder / file | Contents |
|---|---|
| `backgrounds/` | Campus backgrounds and their source notes |
| `life/` | Current student/staff sprites, portraits and outfit atlases |
| `activities/` | Released drawings for purposeful school routines |
| `characters/`, `portraits/` | Earlier source sheets and retained fallback resources |
| `ui/` | Illustrated floor plans |
| `icons/` | Licensed interface icons |
| `title-campus.png`, `portraits.png` | Introduction illustration and retained portrait sheet |

The [character registry](../game/characters.js) and [scene registry](../game/campus-art.js) define which files are used. [Production references and approval records](../../../resources/design/) are kept separately from deployed images. See [asset provenance](../../../ASSET-PROVENANCE.md) before reusing artwork.
