# Production resources

[`design/`](design/) holds original design proposals, approved reference images, production prompts, measured sprite metadata and visual QA captures. These are working records, not automatically released game assets. Pending artwork must still pass the recorded approval process before it is registered in the game.

Use the following folders for the current runnable source and data:

- [Game code](../public/campus/game/)
- [Runtime images](../public/campus/images/)
- [Dialogue audio](../public/campus/audio/)
- [Runtime fonts and licenses](../public/campus/resources/)
- [Question and dialogue data](../data/)
- [User and developer documentation](../docs/)
- [English conversation archive](../Chat%20Recording/README.md)

The main [README](../README.md) provides the public game link and QR code. This resource folder does not contain API keys, production student records or teacher-uploaded worksheets.
